# When Are Umbrellas Actually Useful?

A data analytics project examining umbrella-favorable weather conditions in Chicago and whether public attention aligns with objectively useful umbrella conditions.

## Research Question

When are umbrellas actually useful in Chicago, and does public attention toward umbrellas align with those conditions?

## Data Sources

- Open-Meteo Weather API
- Google Trends

## Methods

- Data cleaning and feature engineering
- Custom umbrella favorability framework
- Time-series analysis
- SQL queries and joins
- Linear regression models

## Key Findings

- Summer exhibited the highest umbrella favorability.
- Winter exhibited the lowest umbrella favorability.
- Weekly weather conditions showed only a modest relationship with search behavior.
- Monthly and seasonal patterns exhibited substantially stronger alignment.
- Public attention appears to track broader seasonal weather cycles rather than week-to-week weather fluctuations.
